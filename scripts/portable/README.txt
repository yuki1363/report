絶縁抵抗測定報告書アプリ（ポータブル版）
==========================================

■ 使い方
  1. zip を右クリック →「プロパティ」→ 下の「許可する」にチェック →「OK」。
     （インターネットやメールで受け取った zip は、これをしないと起動を止められることがあります）
  2. zip を右クリック →「すべて展開」し、好きな場所に置きます（例: C:\Tools\insulation-report）。
     ※ zip のまま実行しないでください。
  3. start.bat をダブルクリックします。
  4. ブラウザが自動で開きます（開かない場合は http://localhost:8787/ を開く）。
  5. 終了するときは、黒いウィンドウを閉じます（または Ctrl+C）。

  ・インストールやインターネット接続は不要です。
  ・Node.js はフォルダ内の node\node.exe を使います（PC には何もインストールしません）。
  ・PDF 出力には PC の Microsoft Edge を使います。

■ データの保存場所（新しい版に更新しても消えません）
  データは、アプリのフォルダの外にある次の場所に保存されます。
    %APPDATA%\InsulationReport\data   （エクスプローラーのアドレス欄にそのまま貼り付けると開けます）
  設定ファイル（.env。API キーなど）も、同じ InsulationReport フォルダにあります。
  そのため、新しい版の zip を別のフォルダに展開して start.bat を起動するだけで、
  これまでの報告書・テンプレート・設定がそのまま使えます。古い版のフォルダは削除して構いません。
  バックアップは、アプリの「設定」画面の「バックアップをダウンロード」を使ってください。

■ 以前の版（データがアプリのフォルダの中にあった版）のデータを引き継ぐ
  方法1: 以前の版のフォルダにある data フォルダを、新しい版のフォルダにコピーしてから、
         初めて start.bat を起動します（自動で引き継がれます）。
  方法2: 新しい版を起動し、「設定」画面の「以前のデータを取り込む」で、
         以前の版の data\app.db を選びます（いまのデータは消えず、追加で取り込まれます）。

■ 設定（.env）
  初回起動時に、上の InsulationReport フォルダに .env が作られます。メモ帳で編集できます。
    PORT=8787            … ポート番号（他のソフトと重なる場合に変更）
    PDF_BROWSER=msedge   … Edge が無い場合は chrome
    #DATA_DIR=...        … データの保存先を変えたいときだけ、行頭の # を外して書き換えます

■ うまく動かないとき
  ・「Windows によって PC が保護されました」と出た場合:
      社内のルールに従ってください（「詳細情報」→「実行」で起動できますが、
      会社の方針で禁止されている場合は情報システム担当に相談してください）。
  ・「既に起動しています」と出た場合:
      別のウィンドウでアプリが動いています。ブラウザで http://localhost:8787/ を開いてください。
  ・PDF が出力できない場合:
      Microsoft Edge がインストールされているか確認してください。
