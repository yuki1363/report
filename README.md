# 配電盤 絶縁抵抗測定報告書アプリ

仕様は [CLAUDE.md](./CLAUDE.md) を参照。**P1〜P4** を実装済み。

## 機能
| 画面 | できること |
|---|---|
| 報告書一覧 | 新規作成、図面から作成、複製、前回値を引き継いで新規、削除 |
| 手入力 | 回路を1行ずつ入力、または「回路を貼り付けて追加」で Excel などの表をまとめて追加（外部 AI 不要） |
| 取込 → 確認・修正 | PDF・画像をドラッグ&ドロップ（複数可）→ 読み取り → 左に元資料・右に結果（要確認は黄色）→ 確定で報告書へ反映（新規／追加／置き換え） |
| 測定値入力 | キーボードだけで入力、判定をリアルタイム表示、前回値との比較（半分未満で赤）、メガー写真からの入力（実験的） |
| 書式編集 ⇄ プレビュー | セルの文字・書式・罫線・結合、列幅/行高のドラッグ、行/列の挿入・削除、差し込み項目、回路行・見出し行の指定、元に戻す/やり直し、コピー/貼り付け。「この報告書だけに適用」と「テンプレートとして保存」を区別 |
| 出力 | PDF（Edge）・Excel（ExcelJS）。同じ帳票モデルから出力 |
| 書式テンプレート | 一覧、複製して編集、名前変更、削除 |
| 設定 | 外部 AI 読み取り ON/OFF、モデル名、判定基準、列幅換算係数、計器マスタ、バックアップ |

## 読み取りの仕組み
- **外部 AI 読み取り ON**（設定画面。既定は OFF）: Claude API（`.env` の `ANTHROPIC_API_KEY`・`CLAUDE_MODEL`）。テキスト PDF は文字と座標＋ページ画像、スキャン PDF・写真は画像で送る。出力は JSON スキーマで固定（構造化出力）。
- **OFF**: テキスト PDF はテキスト層から、スキャン PDF・写真は Tesseract（日本語、オフライン）で読み取る。精度は低いので補助扱い。
- どちらの場合も、確認・修正画面で利用者が確定するまで報告書には反映しない。
- **1つの資料に盤が複数ある場合**（盤ごとの負荷表が並ぶ図面など）は、盤ごとのタブで確認し、チェックを入れた盤の数だけ報告書を作る。
- 読み取りの癖を直したいとき（例: 「210V は 200V の意味」）は、`data/extract-notes.txt` に日本語で指示を書くと AI への指示の末尾に加わる（アプリの作り直しは不要。次の読み取りから有効）。
- 元資料の表示は回転できる（↺ ↻。表示だけで、読み取りには影響しない）。向きの違う図面は、外部 AI 読み取り（ON）の方が向いている。
- PDF の画像化・テキスト抽出はブラウザ側（pdf.js）で行う（サーバーに画像処理用のネイティブ部品を入れないため）。

## セットアップ（Windows）
1. Node.js 20 以上をインストールする。
2. `start.bat` をダブルクリックする（初回は `npm install` を自動実行）。
   - またはコマンドプロンプトで `npm install` → `npm start`
3. ブラウザが自動で開く（http://localhost:8787/）。終了はコンソールで Ctrl+C。

`.env.example` を `.env` にコピーすると、ポート・PDF 用ブラウザ・データ保存先などを変更できる。
PDF 出力には PC にインストール済みの **Microsoft Edge** を使う（Chromium の追加ダウンロードは不要）。

## 書式エディタ単体版（HTML 1ファイル）
報告書アプリ本体を使わず、書式（レイアウト）だけを作って保存したい場合に使う。サーバー・インストール不要で、HTML をダブルクリックするだけで動く。
```
npm run build:format   # dist/format/書式エディタ.html ができる
```
- 標準の書式を読み込む／白紙から作る／書式データ（JSON）を開く
- 保存: **Excel（空欄の様式）**、**PDF（空欄の様式。印刷画面で「PDF に保存」）**、**書式データ（JSON）**
- 作業内容はブラウザに自動保存（消えた場合に備え、JSON での保存を推奨）
- 保存した JSON は、報告書アプリ本体のテンプレートと同じ形式

## ポータブル版（Node.js 同梱・インストール不要）
社内PCに Node.js を入れられない場合や、ネット接続に制限がある場合に使う。

**作成**（インターネットに接続できる PC で1回だけ。Windows / Linux どちらでも可）
```
npm install
npm run package:win
```
→ `release/insulation-report-win-x64.zip`（約 70MB）ができる。
Node.js 本体（v24 LTS）は nodejs.org から取得し、SHA256 を検証して `node.exe` だけを同梱する。
社内プロキシ経由で取得に失敗する場合は、`NODE_USE_ENV_PROXY=1` と `HTTPS_PROXY` を設定して再実行する。

**社内PCでの使い方**: zip を USB・共有フォルダ等でコピー → 展開 → `start.bat`。詳しくは同梱の README.txt。
データは展開先の `data\` に保存される。

## 開発
```
npm run dev         # サーバー(8787) + Vite(5173, ホットリロード)
npm test            # Vitest
npm run typecheck   # tsc（strict）
npm run gen:template  # templates/default.json を再生成
```
実ブラウザでの PDF テストは Windows では自動で実行、他 OS では `PDF_BROWSER=<chrome のパス> npm test` で実行する。

## ディレクトリ
| パス | 内容 |
|---|---|
| `src/shared/schema.ts` | Sheet / Report などの型と zod スキーマ |
| `src/shared/extraction.ts` | 読み取り結果・取込の型と zod スキーマ |
| `src/domain/` | 判定・対地電圧・テンプレート展開・HTML 描画・書式操作・前回値比較（純粋関数） |
| `src/server/` | Hono サーバー、SQLite 保存、PDF（Edge）・Excel（ExcelJS）出力 |
| `src/server/extract/` | 読み取り（Claude API / Tesseract） |
| `src/client/` | React 画面 |
| `templates/default.json` | 既定テンプレート（A4 横） |
| `data/` | SQLite・画像（Git 管理外） |
